## Panel-specific overlay

The transformed design is a liminal memory seal, not an event and not a portrait. Use an axis, nested frames, a light, a path or an entrance, and one small silhouette for scale, solitude or waiting. Line is restrained and slightly imperfect, like a print or an old stamp. Blank is distance and the unknown. Reject a literal scene, many symbols, a busy ground and a decorative frame that explains the picture.

These overlay rules add to `references/soldier-runtime.md`. They never replace the source brief or the family runtime contract.

Write every selected final PNG directly inside one fresh task directory under `~/Desktop/xxd/xxd-panel-336/` (or the explicit `--out` root). Use collision-safe filenames; do not create source, mode, or size subdirectories and do not generate an automatic contact sheet.
